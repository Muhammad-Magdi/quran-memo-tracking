# Manual Smoke Test Checklist

- Clear `localStorage`, reload the app, and verify the welcome tutorial opens.
- Move through tutorial slides, use previous/next, and finish or skip it.
- Add a `قراءة` record by searching with a quad number.
- Add a `تسميع` record by searching with a saved quad name.
- Confirm the recent reads list updates and filters by date, type, and quad text.
- Open history, select a quad, return to the grid, and confirm read counts remain correct.
- Edit a quad name and confirm recent reads, detail title, and grid display update safely.
- Open statistics and confirm summary cards, progress, secondary stats, and heatmap render.
- Reload the page and confirm existing localStorage data still appears.
